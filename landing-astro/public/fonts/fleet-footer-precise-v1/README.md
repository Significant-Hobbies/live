# Precise footer font assets

The published Precise footer runtime uses same-origin OFL-licensed Geist, Geist Mono, and Newsreader WOFF2 assets from this directory. Live's signature inherits the native Fraunces display face; the shared footer UI uses Geist. The exact URLs, hashes, byte sizes, and SIL Open Font License sources are recorded in `provenance.json`, and the unmodified OFL texts accompany each font. No private filesystem path or runtime Google Fonts request is required by the footer.
