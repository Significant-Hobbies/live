## Why

The current 404 is a generic text block and does not belong to the Life Atlas.
Public hobby detail pages already exist dynamically, but the all-catalog
coverage is implicit and can drift as the catalog grows.

## What Changes

- Replace the generic 404 with a colorful public wayfinding surface.
- Offer clear routes home, into hobby discovery, and into experience ideas.
- Add an invariant that every canonical hobby generates one unique detail-page slug.

## Impact

- Public not-found UI and focused route/catalog tests only.
- No schema, dependency, authentication, or deployment change.
